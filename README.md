# Homeland

## About the Project

This project was developed as part of the TripleTen Web Development program.

The project is based on a Figma design and focuses on creating a responsive webpage that adapts to different screen sizes while maintaining the visual structure and design of the original layout.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Figma
- Git
- GitHub

## Responsive Design

The webpage was developed to provide a consistent experience across different devices and screen sizes:

- **320px** — Mobile
- **768px** — Tablet
- **1280px** — Desktop

The layout, typography, images, and spacing adapt according to the screen size following the responsive design requirements of the project.
