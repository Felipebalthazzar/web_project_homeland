# Triple Peaks Coffee Shop

## Descrição do Projeto

O Triple Peaks Coffee Shop é uma página web desenvolvida como parte do Projeto 4 da TripleTen. O objetivo do projeto é construir uma landing page completa para uma cafeteria utilizando HTML e CSS, seguindo a metodologia BEM e boas práticas de desenvolvimento front-end.

A página contém:

- Cabeçalho com navegação e seção principal (hero);
- Seção de receitas com vídeos incorporados do YouTube;
- Formulário para reserva de mesas;
- Rodapé com links para redes sociais;
- Navegação por âncoras entre as seções da página.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Metodologia BEM (Block Element Modifier)
- Flexbox
- Posicionamento CSS
- Google Fonts
- Normalize.css
- Git
- GitHub

## Planos de Melhoria

Algumas melhorias que pretendo implementar no futuro são:

- Tornar o site totalmente responsivo para dispositivos móveis e tablets;
- Adicionar animações suaves para melhorar a experiência do usuário;
- Implementar validação do formulário utilizando JavaScript;
- Criar um menu interativo para a cafeteria com imagens e categorias;
- Adicionar modo escuro (Dark Mode) para melhorar a acessibilidade e a experiência do usuário.
